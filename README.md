# 💔 Apology Cards - React App

Красивое React приложение с фотокарточками для извинения.

## 🎨 Особенности

- ✨ 8 элегантных карточек с трогательными сообщениями
- 📸 Поддержка фотографий на карточках
- 🎠 Плавная карусель с переходами
- 💕 Анимированные сердечки
- 📱 Полностью адаптивный дизайн
- ⌨️ Навигация кнопками или кликом на карты

## 🚀 Как запустить

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск dev сервера
```bash
npm run dev
```

Откроется на `http://localhost:3000`

### 3. Добавление фотографий

Смотри [IMAGES_SETUP.md](IMAGES_SETUP.md) для детальных инструкций по добавлению фото.

**Быстро:**
1. Возьми 6 фото
2. Переименуй их в `image1.jpg`, `image2.jpg`, ..., `image5.jpg`
3. Сохрани в папку `public/`
4. Обнови браузер (F5)

### 4. Сборка для продакшена
```bash
npm run build
```

## 📝 Как редактировать сообщения

Отредактируй массив `cards` в [src/App.jsx](src/App.jsx):

```javascript
const cards = [
  {
    id: 1,
    title: "Заголовок",
    message: "Твое сообщение здесь",
    image: "🌹",  // Эмодзи (если нет фото)
    photo: null,  // Путь к фото или null
    color: "from-red-400 to-pink-300"  // Tailwind градиент
  },
  // ... остальные карточки
]
```
