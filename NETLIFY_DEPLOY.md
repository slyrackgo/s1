# 🚀 Деплой на Netlify (Бесплатный хостинг)

## Что такое Netlify?

Netlify - это бесплатный хостинг для статических сайтов и приложений. Идеально подходит для React приложений!

## ✨ Преимущества:

- ✅ **Бесплатно** - нет платежей
- ✅ **Автоматический деплой** - при каждом git push
- ✅ **SSL сертификат** - защита HTTPS
- ✅ **Быстрый CDN** - глобальное распределение
- ✅ **Просто** - 3 клика для подключения

---

## 📋 Способ 1: Через GitHub (Рекомендуется)

### Шаг 1: Зарегистрируйся на Netlify

1. Перейди на https://netlify.com
2. Нажми **Sign up**
3. Выбери **"Sign up with GitHub"**
4. Авторизуйся своим GitHub аккаунтом

### Шаг 2: Подключи репозиторий

1. После входа нажми **"New site from Git"**
2. Выбери **GitHub**
3. Найди репозиторий **"s1"**
4. Нажми **Deploy site**

### Шаг 3: Готово! 🎉

Netlify автоматически:
- Установит зависимости (`npm install`)
- Собрет приложение (`npm run build`)
- Разместит на своих серверах
- Даст тебе URL вроде: `https://abcd1234.netlify.app`

---

## 📋 Способ 2: Через CLI (Продвинутый)

### Шаг 1: Установи Netlify CLI

```bash
npm install -g netlify-cli
```

### Шаг 2: Логинись в Netlify

```bash
netlify login
```

### Шаг 3: Инициализируй сайт

```bash
cd c:\Users\Atai\Desktop\s1
netlify init
```

Ответь на вопросы:
- **Team**: Your team
- **Site name**: apology-cards (или любое другое имя)
- **Directory to publish**: dist

### Шаг 4: Деплой

```bash
netlify deploy --prod
```

## 🎯 После деплоя

### Твой новый URL:
- Первый деплой: `https://[site-name].netlify.app`
- Пример: `https://apology-cards.netlify.app`

### Что дальше?

1. **Авто-деплой**: Каждый раз когда ты пушишь код в GitHub, Netlify автоматически обновит сайт
2. **Кастомный домен**: Можешь подключить свой домен (платно)
3. **Просмотр логов**: В Netlify UI видны все деплои и логи

## 🔧 Если что-то не работает

### Проблема: "Build failed"

**Проверь:**
- Все зависимости установлены ✓
- `npm run build` работает локально ✓
- Нет ошибок в консоли ✓

### Проблема: "Фото не загружаются"

**Решение:**
- Убедись что фото в папке `public/`
- Фото должны быть названы правильно: `image1.jpg`, `image2.jpg` и т.д.
- Проверь размер файлов (не более 5MB каждое)

### Проблема: 404 ошибка

Это нормально для SPA (Single Page Application). У тебя уже есть `netlify.toml` который это исправляет!

---

## 📊 netlify.toml что делает?

```toml
[build]
  command = "npm run build"    # Команда сборки
  publish = "dist"             # Папка для публикации

[[redirects]]                  # Перенаправление для SPA
  from = "/*"
  to = "/index.html"
  status = 200
```

Это конфиг уже добавлен в проект! 🎉
